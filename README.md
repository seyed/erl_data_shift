# erl_data_shift (アールデータシフト)

## 🎯 <b>Aim and Goals</b>
<b>Aim</b>. Cross-platform CLI for PostgreSQL migrations. 

<b>Goal #1</b>: 
Builds, runs, and verifies database schemas via a simple commands. 

<b>Goal #2</b>: 
Zero dependencies for the end-user.
