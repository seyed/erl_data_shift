## 🎯 الهدف والأهداف

**الهدف.** سطر أوامر متعدد المنصات لترحيلات PostgreSQL.

**الأهداف**

1. بناء وتنفيذ والتحقق من تغييرات مخطط قاعدة البيانات عبر أوامر بسيطة.
2. صفر اعتماديات للمستخدم النهائي.

## كيف تقارن eds مع الكبار

_eds جديدة — هذه أدوات راسخة ومعتمدة على نطاق واسع. إليك نظرة صادقة على أين تنطبق eds وأين لا تنطبق (بعد)._

**أين تنطبق eds:** سطر أوامر صغير، خالٍ من الاعتماديات، للفرق العاملة على Postgres التي تريد أمانًا بنمط Flyway (معاملات، مجامع تحقّق، قفل) دون JVM أو باقة مدفوعة — لا تناسبك إذا كنت بحاجة إلى دعم قواعد بيانات متعددة أو كنت عميقًا بالفعل في إعداد Atlas/Flyway.

### التكلفة والبيانات والتراخيص

| | **eds** | Flyway | golang-migrate | Atlas |
|---|---|---|---|---|
| التكلفة | ✅ (مجاني، بلا باقة مدفوعة — جميع الميزات مشمولة) | ⚠️ (النواة مجانية، لكن التراجع/التشغيل التجريبي يتطلب باقة Teams/Enterprise مدفوعة) | ✅ (مجاني، بلا باقة مدفوعة) | ⚠️ (سطر أوامر مجاني، لكن الميزات المتقدمة خلف Atlas Cloud المدفوعة) |
| جمع بيانات الاستخدام | ✅ (لا يوجد — eds لا يرسل أي شيء إلى أي مكان) | ⚠️ (التقارير المرسلة مفعّلة افتراضيًا، الإلغاء عبر متغير بيئة — [وثائق Redgate](https://documentation.red-gate.com/fd/redgate-disable-telemetry-environment-variable-277579301.html)) | ✅ (لم يُعثر على تقارير مرسلة في وثائقهم/مستودعهم) | ⚠️ (التقارير المرسلة مفعّلة افتراضيًا — الأوامر المنفذة، نظام التشغيل، اسم المضيف — الإلغاء عبر متغير بيئة — [وثائق الخصوصية الخاصة بـ Atlas](https://atlasgo.io/cli/data-privacy)) |
| الترخيص | MIT | مجتمع مجاني / Teams مدفوع | MIT | Apache 2.0 (ميزات سحابية مدفوعة) |

### الميزات والنضج

| | **eds** | Flyway | golang-migrate | Atlas |
|---|---|---|---|---|
| اعتمادية وقت التشغيل | ✅ (لا يوجد — ملف ثنائي واحد، يتضمن ERTS) | ❌ (يتطلب JVM، أو سطر الأوامر الخاص بهم الذي يتضمن واحدًا) | ✅ (لا يوجد — ملف ثنائي Go واحد) | ✅ (لا يوجد — ملف ثنائي Go واحد) |
| دعم قواعد البيانات | ❌ (PostgreSQL فقط) | ✅ (PostgreSQL، MySQL، Oracle والمزيد) | ✅ (كثير) | ✅ (كثير) |
| الترحيلات المعاملية | ✅ (لكل ملف) | ✅ | ⚠️ (يعتمد على المُشغّل) | ✅ |
| التراجع | ✅ (`migrate down`، ملفات `.down.sql` مكتوبة يدويًا) | ❌ (باقة Teams/Enterprise فقط) | ✅ (سكربتات تراجع مكتوبة يدويًا) | ✅ (فرع عكسي محسوب تلقائيًا) |
| كشف انحراف مجامع التحقّق | ✅ (يحظر افتراضيًا) | ✅ | ❌ | ✅ (عبر lint) |
| قفل التزامن | ✅ (قفل استشاري في Postgres) | ✅ | ⚠️ (يعتمد على المُشغّل) | ✅ |
| التشغيل التجريبي / المعاينة | ✅ | ❌ (Enterprise فقط) | ❌ | ✅ (`migrate lint`) |
| مخرجات JSON لـ CI | ✅ | ⚠️ (محدودة) | ❌ | ✅ |
| حجم الملف الثنائي/التنزيل التقريبي | ~40–60 MB* (يتضمن وقت تشغيل Erlang) | ~100+ MB (يتضمن JRE) | ~10–20 MB (ملف ثنائي Go أصلي) | ~15–25 MB (ملف ثنائي Go أصلي) |
| النضج | ❌ (جديدة) | ✅ (10+ سنوات، معتمدة على نطاق واسع) | ✅ (10+ سنوات، معتمدة على نطاق واسع) | ⚠️ (أحدث، تنمو بسرعة) |

\* أرقام الحجم تقريبية وتتغير بين الإصدارات — افحص `ls -lh` على ملف `eds` الثنائي الذي نزّلته أنت وصفحة أحدث إصدار لكل أداة للحصول على الأرقام الحالية الدقيقة بدل الاعتماد على هذه الجدولة.

## 🖥️ الاستخدام

**التثبيت:**
```bash
curl -fsSL https://raw.githubusercontent.com/seyed/erl_data_shift/main/scripts/install.sh | bash
```

أو حمّله يدويًا: احصل على الملف الثنائي لنظام التشغيل الخاص بك من [الإصدارات](../../releases)، ثم `chmod +x eds`.

**الإعداد:**
```bash
eds init          # ينشئ هيكل migrations/ و .env.example في المجلد الحالي
# عدّل .env.example، املأ قيم PostgreSQL الفعلية، احفظه باسم .env
```

## الأوامر

| الأمر | الوصف |
|---|---|
| `con_check` | يختبر اتصال Postgres باستخدام بيانات الاعتماد في `.env`. |
| `stat` | يعرض أسماء الجداول، عدد الصفوف، وحجم التخزين، الأكبر أولًا. |
| `history` | يعرض الترحيلات المطبَّقة — المدة منذ التطبيق، من طبَّق/أعاد كل واحدة، وفحص انحراف محلي/قاعدة بيانات. |
| `migrate` | ينفذ جميع ملفات `.sql` المعلَّقة من `./migrations` بشكل معاملاتي. يرفض إذا تم تعديل ترحيل مطبَّق مسبقًا (انحراف مجامع التحقّق). |
| `migrate force` | نفس migrate، لكنه يتجاوز فحص انحراف مجامع التحقّق. استخدمه بوعي، لا كافتراضي. |
| `migrate dry-run` | يعرض قائمة بالترحيلات المعلَّقة دون تنفيذها. |
| `migrate down` | يعيد آخر ترحيل مطبَّق. |
| `migrate -f <path>` | نفس `migrate`، لكنه يشير إلى مجلد ترحيلات مخصص. |
| `new <name>` | ينشئ زوج ملفات ترحيل up+down مرقَّم جديد. |
| `validate` | يشغّل الترحيلات المعلَّقة في معاملة مُعادتها لكشف الأخطاء مبكرًا. |
| `verify` | يتحقق من أن ملفات الترحيل المطبَّقة لم تُعدَّل منذ تنفيذها (انحراف مجامع التحقّق). |
| `init` | ينشئ هيكل `migrations/` و `.env.example` في المجلد الحالي. |
| `--version` | يطبع إصدار `eds`. |
| `--help` / `-h` | يعرض رسالة المساعدة هذه. |
